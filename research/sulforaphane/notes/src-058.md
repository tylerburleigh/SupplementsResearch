## Study Design

- **Design:** 12-week, double-blind, randomized controlled trial with 2x2 factorial design
- **Sample size:** N = 144 older adults
- **Population:** Healthy older adults (exact age range not specified in abstract)
- **Arms (4 groups):**
  1. BT-S: Brain training (Brain Age) + sulforaphane
  2. BT-P: Brain training (Brain Age) + placebo
  3. AT-S: Active control (Tetris) + sulforaphane
  4. AT-P: Active control (Tetris) + placebo
- **Dosing:** SFN supplement taken daily for 12 weeks (dose not specified in abstract)
- **Brain training protocol:** 15 minutes/day for 12 weeks

## Key Findings

1. **Processing speed:** Brain training groups (BT-S + BT-P) showed greater improvement in processing speed than active control groups (AT-S + AT-P).
2. **SFN-specific effects on processing speed and working memory:** SFN intake groups (BT-S + AT-S) showed significant improvements in processing speed and working memory compared to placebo groups (BT-P + AT-P).
3. **No synergistic effect:** No evidence that the combined BT + SFN intervention provided additional cognitive benefit beyond either intervention alone. This is a notable null finding.

## Methodology Notes

- Double-blinded, randomized design with active control (Tetris) -- strong methodology
- 2x2 factorial design allows separation of BT effects, SFN effects, and interaction effects
- Multiple cognitive functions measured pre- and post-intervention (specific tests not listed in abstract)
