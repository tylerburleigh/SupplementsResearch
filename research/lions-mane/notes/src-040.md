# src-040: Hericium erinaceus Improves Recognition Memory and Induces Hippocampal and Cerebellar Neurogenesis in Frail Mice

**Source quality:** Degraded (paywall). Metadata flagged as degraded due to paywall. Content contains abstract + figure captions with experimental detail, but full text (methods, results, discussion) is not available. PMID: 30934760. Published in MDPI journal (likely Nutrients or similar).

## Core Findings

Two-month oral supplementation with Hericium erinaceus reversed age-related decline in recognition memory in a physiological aging mouse model. The study developed an integrated frailty index combining locomotor and cognitive decline, demonstrating these decline in parallel during aging. Neurogenesis markers (PCNA and DCX) showed enhanced cell proliferation in the hippocampus (dentate gyrus granule cells, CA3 pyramidal neurons) and cerebellum (molecular layer) of treated mice.

## Key Evidence and Data Points

1. **Recognition memory reversal:** Two-month oral H. erinaceus supplementation reversed age-related decline in recognition memory measured by Novel Object Recognition (NOR) test (discrimination index).
2. **Bioactive compound identification:** HPLC-UV-ESI/MS analyses identified and standardized erinacine A, hericenone C, and hericenone D in the H. erinaceus extract (designated He1). Erinacine A from mycelium fraction; hericenones C and D from sporophore fraction.
3. **PCNA (cell proliferation) results:** Significantly enhanced in He1-treated mice in hippocampal DG granule cells, CA3 pyramidal neurons, and cerebellar molecular layer (p < 0.05).
4. **DCX (neurogenesis) results:** Enhanced doublecortin labelling in hippocampal dentate gyrus (p < 0.01) and cerebellar molecular layer (p = 0.07, trend) in He1-treated mice.
5. **Integrated frailty index:** Novel contribution combining locomotor parameters (open arena: distance, speed, resting time) and cognitive parameters (emergence test: latency, exit number, exploring time; NOR: discrimination index) into a single LAC (Locomotor And Cognitive) Frailty Index.
6. **Longitudinal aging assessment:** Mice assessed at multiple timepoints (T0-T4 for aging characterization; T5 post-supplementation) tracking progressive decline.

## Methodology

- **Animal model:** Wild-type mice undergoing physiological aging (not genetically modified). Age-equivalence mapping from mouse to human lifespan referenced (Dutta and Sengupta, 2016).
- **Supplementation:** He1 extract (H. erinaceus) administered orally for 2 months.
- **Behavioral tests:** Open arena (locomotor), emergence test (cognitive), Novel Object Recognition (NOR) for recognition memory.
- **Histological analysis:** PCNA immunohistochemistry for cell proliferation; DCX immunocytochemistry for immature neurons/neurogenesis. Brain regions examined: hippocampus (DG, CA3) and cerebellum (molecular layer).
- **Analytical chemistry:** HPLC-UV-ESI/MS for compound identification and standardization of erinacine A, hericenone C, hericenone D.
